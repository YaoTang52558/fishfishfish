# fishfishfish 产品需求文档

版本 0.5 · 2026-10-06 · 产品工作名：我的海洋 / My Ocean。核心双玩法与 3D 候选版已实现，真机／亲子验收待完成；实时状态见 [PROJECT_STATUS.md](PROJECT_STATUS.md)。本文定义需求，不代替验收结果。

## 1. 产品目标

让孩子创造一条属于自己的鱼，看它游进一个可再次访问的海洋；也能单独通过钓鱼发现真实鱼类。两个玩法有各自完整的乐趣，共享图鉴、创作灵感和海洋中的偶遇。

首版验证三个假设：孩子愿意尝试不同部件并观察试游变化；自由绘画让作品有个人特征；玩家能从任意玩法开始，而不会被另一个玩法卡住。

目标用户暂按 6–10 岁儿童与亲子共玩设计。主要设备为 iPad、桌面浏览器，兼容手机触摸。默认简体中文；真实物种卡保留学名字段。首作目标 3–8 分钟；新版 3D 钓鱼单轮目标约 20–40 秒，知识卡阅读不计入，均为待试玩验证的目标。

## 2. 体验原则

1. 首页直接显示“创造鱼”“去钓鱼”“我的海洋”；不强制顺序，不要求注册。
2. 基础部件、颜色、画笔和两处首版钓场始终可用。发现图鉴条目不会成为创作权限。
3. 创作至少包含可控塑形、自由绘画、试游反馈三个维度，不能只有换装按钮。
4. 科普可主动展开，首次简短提示不阻塞操作；不设置必答题。
5. 幻想规则明确标作“游戏设定”；真实鱼类资料独立审核。
6. 作品先成功保存再入海。离开后作品持续存在，但不虚构后台持续模拟或实际游动距离。

P0 是完整 MVP 必须通过的要求；P1/P2 是后续候选，不是本轮默认开发任务。

| 钓鱼 | 2 钓场、12 真实鱼种、3 鱼饵、3D 海面抛竿／拉鱼、选落点、咬钩判断、控竿／收放线、临岸与放生 | 更丰富鱼类模式与场景 | 开放海洋、深海 |

首版不做金币、商城、体力、签到、每日任务、账号、付费、公共分享或排行榜；不把素材增加等同于交互完成。资产数是内容目标，M1 切片可使用较少素材，完整 MVP 仍需补齐。

## 4. 页面与用户流程

| 页面 | 主要内容 | 主要操作 | 空状态/返回行为 |
| --- | --- | --- | --- |
| 首页 | 三个平级入口、图鉴入口、音量与数据设置 | 直接进入任一玩法 | 无作品也能看示范海洋，示范鱼不记入收藏 |
| 创造工坊 | 中央鱼画布，部件/颜色/画笔工具，保存状态 | 塑形、拼装、绘画、撤销、试游 | 有草稿时提供继续或新建；新建前确认替换草稿 |
| 试游池 | 同一条鱼的动态表现，风格说明 | 返回编辑、命名、放入海洋 | 返回保留编辑状态和撤销记录 |
| 我的海洋 | 原创鱼与已发现物种的示意访客 | 点击查看、重新编辑、选择展示 | 访客明确标识为图鉴展示，不是被搬走的野生鱼 |
| 钓场 | 环境线索、落点、鱼饵、操作提示 | 抛竿、提竿、收线/放线、退出 | 空白账号直接可玩；失败可立即重试 |
| 捕获卡 | 鱼种、观察提示、可展开知识 | 放生、收藏灵感 | 观察和知识可跳过，不挡放生 |
| 图鉴 | 海洋发现 / 我的创造 | 看卡片、按已发现筛选、去创作 | 未发现物种显示轮廓；已有作品不需要发现条件 |
| 设置 | 音量、辅助操作、备份、数据说明 | 导出、导入、清空 | 清空明确二次确认 |

造鱼：选基础体型 → 调比例/部件 → 配色与绘画 → 试游 → 可回改 → 命名 → 保存并入海。

新版钓鱼：选钓场 → 3D 海面观察 → 选饵与落点 → 等待咬钩 → 提竿 → 海面控竿／收放线 → 临岸抄起 → 鱼卡 → 放生 → 可选择使用灵感。2026-10-06 用户反馈后，完整流程保持海面场景；水下仅保留在开发三动作练习。

## 5. 工坊需求

| ID | 功能与规则 | 验收标准 |
| --- | --- | --- |
| C-01 | 5 类身体：流线（梭形）、圆（球形）、侧扁、细长（鳗形）、三角（参考鳐等扁平鱼的轮廓）；5 类头型：圆钝、尖吻、方头、隆额、铲形。头型与身体分别选择、任意组合，头仍是同一轮廓内的独立绘制区域 | 任意身体×头型均能进入试游；头身连接处没有断裂、台阶或缝隙；所有必需部件有默认值 |
| C-02 | 长度 0.75–1.4、高度 0.7–1.3、头身比例 0.2–0.4；拖动控制点或滑块均可 | 不出现断裂或部件脱落；极值组合仍可使用；恢复默认不清除绘画 |
| C-03 | 6 尾：新月、分叉、截形、圆形、菱形、飘带；6 套鳍：软鳍、棘背鳍、长飘鳍、帆鳍、连续鳍、小圆鳍；5 眼；5 嘴：端位、上位、下位（带须）、伸缩、细长。点击替换，固定连接位自动吸附 | 切换即时反馈，撤销能恢复；任意身体、头型、尾、鳍、嘴组合都连接正常；不要求精细拖拽到像素位置 |
| C-04 | 身体、头、鳍、尾分别设底色；10 预设花纹可调主/辅色；另设“无花纹” | 模板更换不覆盖自由画层；“应用灵感”只更改底色和花纹，作为一次可撤销操作 |
| C-05 | 普通画笔含粗细；一笔是一个撤销单位；橡皮只擦自由画层；绘画限制在身体轮廓内 | 触摸与鼠标可连续画；不涂出身体，不误擦底色、眼睛；转向与再次进入后花纹一致 |
| C-06 | 6 印章：海星、贝壳、泡泡、闪电、爱心、花；选择后拖动、旋转、缩放、删除 | 最多 24 枚，触摸有按钮式旋转/缩放替代；印章裁剪在身体内 |
| C-07 | 发光笔绘制独立发光图层；工坊有暗背景预览 | 试游和海洋都保留发光；不把发光描述为真实生物功能 |
| C-08 | 至少 30 步撤销/重做；随机造型先预览，再应用；清空绘画需确认 | 未应用随机结果不改变草稿；整次随机应用可一次撤销；新操作清空 redo |
| C-09 | 试游默认 15 秒，可继续看；清楚展示速度、摆尾与转向风格 | 只改尾巴也能看到可解释差异；“换个尾巴试试”返回对应工具 |
| C-10 | 名字 1–16 个可见字符，可用默认名；性格从轻快/悠闲/好奇中生成推荐，可人工改选 | 无贬损标签；改配色不强制改变性格；同配置生成推荐可复现 |
| C-11 | 三种组合彩蛋见下表；满足条件自动显示，可关闭效果 | 不改写原始部件或笔迹，不提供钓鱼概率优势，不解锁专属工具 |
| C-12 | 保存成功后出现 3–5 秒入海镜头，可跳过；镜头追踪新鱼 | 重复点击只生成一条；保存失败留在草稿并可重试；跳过仍能定位新鱼 |

两侧绘画规则：P0 使用同一侧面纹理，鱼转向时整体镜像显示；这不是画面左右对称画笔，不在身体中间重复一份图案。P1 才考虑两个独立侧面和可选镜像同步。

| 彩蛋 ID | 条件（游戏设定） | 效果 |
| --- | --- | --- |
| FX-01 星夜鱼 | 大眼睛 + 深蓝底色 + 至少一笔可见发光笔迹 | 附加少量星点，名称标签“星夜漫游者” |
| FX-02 飘带鱼 | 飘带尾 + 波浪花纹 | 慢速尾部光带，名称标签“海流舞者” |
| FX-03 泡泡鱼 | 圆身体 + 泡泡印章 | 间歇泡泡，名称标签“泡泡伙伴” |

多条件同时满足时按 FX-01 → FX-02 → FX-03 选一个显示效果，其他仍记为已发现；只有保存作品时写入彩蛋图鉴。移除条件后视觉效果消失，发现记录保留。彩蛋不得用“科学变异”解释。

## 6. 钓鱼需求

下表为现行 3D 钓鱼需求。两场 12 物种、完整流程、教学与自动画质已在开发／候选构建实现；正常正式构建仍保留旧版，待 G5 真机与试玩验收后替换。阶段设计见 [FISHING_3D_DESIGN.md](FISHING_3D_DESIGN.md)，验收状态见 [PROJECT_STATUS.md](PROJECT_STATUS.md)。

首版两处场景是虚构的“珊瑚外缘”和“近岸岩礁”，与现实允许垂钓地点无对应关系。游戏中的鱼饵吸引权重是难度配置；物种卡的真实食性另存。

| ID | 功能与规则 | 验收标准 |
| --- | --- | --- |
| F-01 | 两钓场初始开放，各 6 个主要物种；3 饵：虾型、藻食型、拟饵，无消耗 | 空白存档可完成两处体验；无需造鱼、金币或升级 |
| F-02 | 3D 海面角色背后视角，每场 3 落点：近处/中段/远处；气泡或鱼影提供概率线索 | 点击涟漪或 HTML 按钮发送相同落点；键盘可选；不强制精细抛竿 |
| F-03 | 等待 3–8 秒后进入咬钩提示，默认提竿窗口 2.5 秒；提竿成功后保持海面拉鱼 | 窗口前空竿，窗口后可重试；教学打开时暂停同一轮窗口；静音仍可判断 |
| F-04 | 左右控竿，按住收线，松开放线；鱼位置、浮漂、张力、竿弯曲与线形读取同一规则，鼓轮随实际收线量转动 | 收线能靠岸，松线能缓解拉力；松线／暂停停轮，减少动态用文字反馈；取消／离开／失焦释放输入，支持双指与键盘 |
| F-05 | 冲刺／横游／下潜／喘息有动作预兆；距离、深度与疲劳满足条件进入临岸，轻轻抄起；大小按物种配置改变拉力与耐力 | 不靠独立进度条判胜；搏鱼目标 12–22 秒仍待试玩校准；小鱼硬超时 60 秒、大鱼 72 秒；固定步保持不同帧率难度一致；临岸无严苛 QTE |
| F-06 | 连续失败两次建议辅助；始终可以手动启用 | 辅助提竿 5 秒、协助竿向、放宽过紧容错并可自动抄起；不降低发现记录 |
| F-07 | 仅成功抄起后提交捕获记录；卡片显示可跳过的观察问题和知识，“放生”结束本轮 | 事务成功后才显示已记入图鉴；失败可重试，放生后本页仍可补记；刷新不重复发放发现；无背包占用 |
| F-08 | 已发现重复鱼仍可捕获；显示“再次遇见”，保留第一次发现时间 | 不重复制造图鉴条目，不把重复鱼直接算原创作品 |

12 种鱼的中文名、学名、食性、外形和栖息地已在步骤 08 核对并记录来源；G4 接入对应模型。新增物种仍需独立内容审核，占位数据不能通过完整 MVP 验收；专业人士复核属于后续质量建议。

| 钓场 | 物种 |
| --- | --- |
| 珊瑚外缘 | 眼斑双锯鱼、黄高鳍刺尾鱼、黄尾副刺尾鱼、黄镊口鱼、纹腹叉鼻鲀、角镰鱼 |

## 7. 我的海洋与两个玩法的关系

| ID | 规则 | 验收标准 |
| --- | --- | --- |
| O-01 | 原创鱼保存上限 30；同屏最多 20，含图鉴访客；未展示的作品仍在图鉴中 | 第 31 条保留草稿，提示先删除或备份作品；不静默覆盖；可切换展示鱼 |
| O-02 | 原创鱼有巡游、停留、转向三种状态，点鱼弹卡；卡中有创建时间、性格、再次编辑 | 不显示未经统计的游动公里数；离线不死亡、不扣资源、不增加虚构故事 |
| O-03 | 再次编辑默认更新同一条鱼，也可“另存为新鱼”；已保存版本不随草稿实时变化 | 取消编辑恢复海洋中的原版；另存新增 ID；保存更新不重复入库 |
| O-04 | 删除作品需确认，仅删除该原创作品；已发现的真实物种条目保留 | 删除失败不移除画面；删除成功清理对应可见列表和引用 |
| L-01 | 首次发现物种，解锁对应图鉴卡并出现可选“用这个配色创作” | 工坊本来就能手动得到这些颜色和花纹；跳过提示仍可继续钓鱼 |
| L-02 | 已发现真实物种可在海洋中作为一个示意访客展示 | 相同物种最多一名访客；标“物种访客”；不声称放生的野生鱼进入私人海洋 |
| L-03 | 原创鱼保存时默认一个喜爱区域，玩家可改；在对应钓场偶尔路过 | 每个场次最多一次，满足条件后独立按 20% 初始概率触发；不干扰咬钩窗口 |
| L-04 | 首版原创鱼只路过，点击问候；不进入捕获候选池 | 不能丢失、复制、出售或钓走原创鱼；没有原创鱼时真实鱼概率不变 |
| L-05 | 图鉴分“海洋发现”和“我的创造”，彩蛋作为创造页的发现标记 | 真实物种与原创幻想鱼的性质一目了然；发现数与原创数独立统计 |

区域偏好与性格只是游戏设定，不能从深色身体推导“适合深海生存”。首版未开放深海，也不通过造鱼配件暗示存在可进入的深海关卡。

| D-05 | 切后台暂停钓鱼计时、动画和音频，返回保持状态 | 不因切应用超时失败；关闭浏览器后钓鱼本轮重置，不丢已记录发现 |

## 9. 内容与美术规范

暖色工具面板、清晰鱼轮廓、分层海水与轻微光线营造轻松感；参考自然水族箱与手工绘画，不复制其他游戏的素材。鱼的身体、尾鳍、胸鳍需可辨认，避免全部用 emoji 或一张整体 PNG 代替可编辑模型。

美术产出需覆盖 5 体型、5 头型、6 尾、6 鳍、5 眼、5 嘴、10 花纹、6 印章、12 色卡、2 场景、12 真实鱼外形及 3 彩蛋。素材的锚点、裁剪、授权要求见技术文档。首版简单矢量素材可以合格，前提是体型与动画差异清楚。

新版钓鱼另需真实 3D 场景、角色、竿线浮漂与 12 物种模型；明确模型朝向、鱼嘴锚点、动画和来源。上句矢量标准继续适用于工坊、海洋与图鉴，不能替代 3D 钓鱼模型验收。确认的概念图见 [设计参考](../design/fishing-3d-concept.png)，素材清单与质量预算见 3D 实现设计。

拼接部件参考鱼类形态学中常见的体型、口位和尾鳍形状分类，自行绘制原创矢量，不描摹参考图。风格为清晰剪影加分区配色：每个部件单独看能认出类别，任意组合后仍是一条完整、连贯的鱼，而不是拼在一起的几块图形。部件可用“新月尾”“上位嘴”等名称帮助认识鱼类，但部件带来的游动差异是游戏设定；与之相关的科普说法须按真实鱼内容的规则单独核实。

真实鱼每种最少一条核实后的知识；每条内容记录来源链接和查阅日期。禁止沿用未验证的概括，例如“斑马纹提供完美伪装”“大眼睛就是夜视”“大尾巴必然游得快”。

## 10. 验证方式与上线门槛

功能门槛：所有 P0 通过；只有造鱼完成不算完整 MVP。体验试玩建议邀请 5–8 组目标年龄亲子：先自由选择入口，再各自体验第二入口，观察能否独立完成首作、是否主动回试游修改、是否理解自己的鱼可以再次找到。小样本用于发现障碍，不作为统计结论。

建议观察指标：首作完成率、完成耗时、试游后修改次数、首次钓鱼成功次数、找回原创鱼耗时。首版可通过主持人记录或本地调试事件观察；不默认上报儿童姓名、笔迹或浏览行为。

性能和数据门槛见技术设计与实施计划。内容、交互或存档不合格时优先修正，不以扩充素材数量替代修复。
