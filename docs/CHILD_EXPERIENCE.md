# 小学一二年级体验与整改

2026-10-07 · 目标是让孩子直接创造、认出自己的作品，并从好奇出发学习。原审核基线 `4068ce4` 的问题和依据保留在 [审核档案](archive/2026-10/PRODUCT_CHILD_REVIEW.md)。以下是这一轮实际调整；孩子体验和真实 iPad 结果仍待验证。

| 审核问题 | 当前调整 | 仍需观察 |
| --- | --- | --- |
| 首页核心入口不突出 | 缩短介绍，首屏突出大按钮「造一条鱼」；有草稿或作品时显示真实设计和「继续我的鱼」 | 是否能自主开始和辨认作品 |
| 画布默认不能画，菜单偏多 | 默认画笔；大鱼旁集中画／擦／颜色／捏形；颜色盘就近；随机、背景、新建和作品近看按需展开 | 手指遮挡、误触、工具状态是否理解 |
| 塑形在另一张小图里 | 主画面六个背／腹把手直接拖；一次拖动一步撤销，方向键和旧滑杆仍可用；拖动中固定相机，笔迹保留 | 极端造型、手指点选与捏形手感 |
| 帮助需要二次找播放 | 主动点帮助就播放，可停／重听／关闭；增加图形手势提示，减少动态时不动；新增捏形声音 | 合成声音的理解度与节奏；提示目前不是完整操作动画 |
| 学习入口命名不符 | 改为「看看真鱼」，根据当前尾／鳍／嘴／身体进入对应主题，仍允许自由切换 | 是否从观察得到一个新创作想法 |
| 图鉴先筛选，观察图靠下 | 大图优先，找鱼筛选折叠；钓过的记录单独展开；30 张观察卡与 12 种钓鱼池继续分开 | 孩子能否找鱼和指认部位，比较是否有用 |
| 首次钓鱼帮助不明显 | 教学首步可明确选「帮我一下」或「我自己来」，修改辅助／挑战并保留知识设置 | 一竿自然时长下的提竿、收放线和失败恢复 |
| 开发信息和整理存档干扰 | 导航改为「家长」；海洋记录器收进家长工具，清空数据折叠且保留两次确认；显示层去掉样板字样 | 这只是入口整理，没有增加密码锁或同步服务 |

## 保留的交互与数据规则

幻想与真实物种不互相限制；所有创作工具和鱼都开放。试游可跳过，名字可用默认值；普通／发光笔迹、印章、塑形、存档与备份格式保持兼容。更新原作与另存仍明确区别；本机全屏不跨设备发送。不会按年龄自动升难度或增加每日任务。

首页只读取本机草稿／最近修改作品，缩略图包含本机笔迹，页面离开释放位图。已有草稿时主按钮显示「继续画这条鱼」，进入同一工坊，仍需在「更多→新建一条」明确确认后才替换草稿，避免首页隐式清空。

观察有来源，但程序鱼运动与幻想造型仍是游戏设定。当前参数三维只是可行性样板；界面名称简化没有改变完成口径。

## 待做与试玩

先做一次 10–15 分钟亲子试玩：创造想要的鱼→入海→找回修改；看一条真鱼并指出一个特征；钓鱼后放生。记录哪里点了无反应、哪里需要大人读字、是否找到声音、是否认得自己的鱼和是否主动产生新想法。卡住后提供帮助，不先逐个解释所有按钮。

美术风格统一、完整手势示范、特殊鱼结构、更多海洋行为、满容量作品管理仍在计划中；由实际反馈决定细化顺序。此短试玩不替代 [G5](G5_PLAYTEST.md) 的 iPad、VoiceOver、性能与正式家庭验收。

本轮浏览器流程见 [记录](evidence/child-experience-browser.json)，使用隔离数据和桌面 Edge 的 1024×768、768×1024、390×844 视口；不宣称真实儿童或 Safari 已验收。临时截图留在 `.verification/child-experience/`，不提交。
