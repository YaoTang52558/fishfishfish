# 最新完整计划

2026-10-08 · 核心：孩子自由造鱼，发挥想象力，从创作学习海洋生物；钓鱼提供发现，探索丰富世界。帮助、挑战和知识深度独立手动调整，不按年级自动升难度，不要求每日游玩。

当前实现与证据看 [项目状态](PROJECT_STATUS.md)，儿童操作整改看 [儿童体验](CHILD_EXPERIENCE.md)，原讨论见 [历史产品计划](archive/2026-10/PRODUCT_EVOLUTION_PLAN.md)。下表保留已确认的 20 项范围，功能已接入不等于最终品质和真机验收完成。

| 编号 | 项目 | 当前状态 | 下一步 |
| --- | --- | --- | --- |
| 01 | 整体美术与画面品质 | 创作／海洋／钓场已有视觉样板 | 统一鱼、环境、光线、镜头与动作，实际评审 |
| 02 | 创作工坊与平板布局 | 大鱼就近部件、默认画笔、快捷颜色／擦笔／主画面塑形、更多项折叠 | iPad 手指遮挡、误触和纵向滚动 |
| 03 | 创作→试游→入海→再编辑 | 闭环、默认名字、更新／另存；首页继续草稿或作品 | 孩子自主保存、认作品和修改 |
| 04 | 海洋与作品互动 | 双主题、点选、找鱼、泡泡、跟手指 | 比例、重叠、行为与反馈 |
| 05 | 图形教学与语音 | 主动帮助直接播放，可停／重听；增加图形提示 | 真实理解度与完整手势示范 |
| 06 | 从创作进入知识 | 七主题、短句语音、画布旁参考、可预览借色／花纹；按当前部位进入 | 孩子是否理解点子并带回创作，参考卡是否易找到 |
| 07 | 正式图鉴 | 119 伙伴、分类／俗名搜索、点听、比较；大图优先 | 找鱼和比较的实际体验 |
| 08 | 知识深度与生态关系 | 小丑鱼伙伴／食物与两地观察 | 按兴趣选新关系，不虚构生态模拟 |
| 09 | 两个钓场差异 | 地形／水色／落点／声音不同 | 构图、精细程度和真机帧预算 |
| 10 | 钓鱼操作与手感 | 场景内鱼饵／抛竿、中央控竿与鼓轮；首次明确选择帮助 | 自然时长的等待、收放线和失败恢复 |
| 11 | 拉上鱼与庆祝 | 连续抄鱼、同一鱼和彩色反馈 | 镜头／动作表现 |
| 12 | 随成长调整 | 手动预设，帮助／挑战／知识独立设置 | 用真实试玩调系数 |
| 13 | 资料素材与模型 | 119 观察伙伴／12 钓鱼；七创作主题、两地观察和参数模型 | 本批常见海鱼与海鲜已制作；后续按用途选择，见素材计划 |
| 14 | 收藏、找回与备份 | 筛选、排序、名字查找、PNG 鱼卡、完整备份 | 满容量保护和家长管理；暂无同步 |
| 15 | 探索与新场景 | 两地来源明确的观察入口 | 更多场景／生物按反馈扩展 |
| 16 | 创作自由度与新结构 | 六点主画面塑形，撤销／笔迹／存档保留 | 任意轮廓、独立两侧、触须和专用鱼结构 |
| 17 | 完整三维与海洋 | 立体转看和 20 鱼海洋可行性样板 | 最终美术品质、特殊结构和 iPad 性能 |
| 18 | 电视／大屏／跨设备 | 本机全屏已接入 | 用户确认不跨设备，暂无中转服务 |
| 19 | iPad 与家庭试玩 | 表单、平面／立体海洋和钓场记录工具 | 实际 iPad、VoiceOver、冷启动和家庭结果 |
| 20 | 版本与发布 | GitHub 分支和局域网；正常／候选构建 | 正式 3D 入口依 G5 验收，公网以后再定 |

优先顺序：孩子短试玩→修自主操作卡点→统一当前美术和反馈→根据孩子想创作的对象补结构与资料→补 G5 正式证据。完整三维、更多海洋和物种制作保持在计划内，不将可行性样板记为最终完成。

日常开发按影响范围核对；阶段提交再做规定回归与构建。原 G5 的 5–8 组亲子要求保留，首轮自己孩子的短试玩不替代它，也不是继续制作的阻碍。
