# 《我的海洋》最新完整计划

2026-10-07 · 汇总当前交付、已确认方向和仍待讨论的扩展。本文作为最新总览；早期讨论与决定过程保留在 [产品迭代计划](PRODUCT_EVOLUTION_PLAN.md)，实现及证据见 [项目状态](PROJECT_STATUS.md)。优先级是建议实施顺序，待开发事项不等于已开工。

## 1. 已确认的产品方向

- 核心是自由造鱼：让在新加坡读小学一年级的孩子发挥想象力，再从创作认识海洋生物。参考用户提供的新加坡海洋馆创作体验，结合平板重新设计。
- 钓鱼与探索提供发现和灵感。钓场内部以钓鱼为主要玩法，探索让世界更有意思。
- 画面与操作要有游戏品质；知识以图片、观察与短语音回应好奇，可跳过、停止和重听。
- 帮助、挑战和知识深度可以随成长手动调整，各自独立；不要求每日游玩或定时照顾。
- 当前目标设备是 iPad 9 或同等平板。先做可玩的样板、收集家庭反馈，再扩展。

## 4. 建议的实施顺序

2026-10-07 用户指定先做 1–3，随后要求接着做 4–12；两批首版已接入，分别见 [创作工坊](WORKSHOP_STUDIO.md) 与 [海洋、知识和钓鱼集成](LEARNING_PLAY.md)。用户随后要求继续剩余项目，13–20 的功能与可行性样板见 [后续交付](REMAINING_STAGE.md)。公网以后再定，大屏按用户选择仅本机全屏。当前先评审全部已实现的体验，并补真机／家庭证据。

1. **评审当前样板。** 先看创造、近看、海洋图片卡与泡泡，记录具体不满意的画面和操作；能拿到 iPad 时同步做一次短试玩。
2. **修正创作与学习的具体问题。** 图形工具、大预览、短帮助、嘴巴学习已接入；依据孩子操作反馈修正，保留笔迹、历史、试游和保存。
3. **评审图鉴与知识样板。** 30 鱼图鉴、两鱼比较、嘴巴与小丑鱼关系已接入；根据兴趣扩更多观察主题，不先追求数量。
4. **细化钓场品质。** 两场结构、图形鱼饵、中间收放线、连续抄鱼、庆祝和手动档位均已接入首版；依据自然时长试玩细化画面与系数。
5. **完成真机与阶段发布。** 当前版本的 iPad 功能、性能、数据与读屏检查通过，修主要障碍，整理提交及正式入口；公网发布另按用户选定的平台安排。
6. **选择性扩展。** 根据兴趣扩物种和主题；更大的创作自由、完整三维、大屏联动另行讨论。

这是一份完整待办，不要求一次做完。每轮选一个明确样板，不承诺尚未评估的天数，也不把开发顺序当作每日游玩目标。

## 5. 验收与发布工作

- 当前样板先围绕这位孩子的自主创作、认作品、理解操作与兴趣做短试玩。原 G5 正式验收中的 5–8 组亲子试玩要求保留在 [试玩表](G5_PLAYTEST.md)，尚未完成；是否调整正式验收的家庭范围须另行讨论，本次不更改该发布基线。多人招募不是继续制作当前样板的前提。
- 正式验收覆盖 iPad 真实触摸、画笔跟手、横竖屏、后台恢复、静音／点听／减少动态和 VoiceOver；普通／发光笔迹经变形、试游、保存、刷新、再编辑及备份仍完整。
- 性能分别检查两钓场与自己的海洋 20 鱼；旧桌面结果不能替代当前画面在 iPad 的证据。原 G5 目标、冷加载与记录方式继续见试玩表。
- 正式 3D 钓鱼入口仍待验收切换。最新文档与开发代码保存不等于已经推送 GitHub 或公网部署。
- 日常开发按影响范围检查：文档查链接；布局／动画看相关画面和输入；规则／存档跑相关检查。阶段收尾或发布再做一次完整回归与对应构建。
