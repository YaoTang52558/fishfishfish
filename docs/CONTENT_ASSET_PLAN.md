| 产品用途 | 资料问题 | 最终能用于什么 |

| 自由造鱼 | 真实生物有哪些体形、嘴、鳍、尾巴和花纹？怎样提供想象的起点？ | 部件参考、局部对比、配色与图案灵感；创作权限不受知识进度限制 |

| 自己的海洋与钓场 | 环境怎样有层次？哪些生物与景物可在同一主题中出现？ | 场景构图、模型／插画、环境动态和探索线索 |

优先做孩子看得见、可以尝试并可能产生好奇的内容。原始资料保留深度，儿童入口每次只讲一个意思。

## 3. 首批范围：先一份样本，再三鱼与一个环境主题

### A 批：把整理方式做清楚

选现有眼斑双锯鱼（`Amphiprion ocellaris`），围绕花纹创作与认识它的生活环境，交付一份完整资料样本：

- 一份物种身份与逐项事实记录。
- 三个观察入口候选：整体轮廓、白带位置、鳍／尾等局部；最终选哪个服从资料与孩子兴趣。
- 一份“我的花纹 → 看真实生物 → 回来再画”的创作联系草案。
- 一种与它关系有证据的海葵候选，明确到物种，不把所有海葵视作同一种伙伴。
- 图像／动作参考及素材可用状态；一句介绍、三条点听知识和一份亲子解释草案。

先核对样本的字段、证据和孩子文案，再复用模板。资料审核与玩法实现分开推进。

### B 批：扩大到有明显差异的创作参考

| 对象 | 建议主题 | 首批用途 |
| --- | --- | --- |
| 眼斑双锯鱼 `Amphiprion ocellaris` | 花纹与生物关系 | 颜色／花纹灵感、图鉴样本、一个关系观察点 |
| 黄镊口鱼 `Forcipiger flavissimus` | 嘴与觅食 | 嘴形局部参考及有证据的原因解释 |
| 纹腹叉鼻鲀 `Arothron hispidus` | 体形、点状花纹与动作 | 与前两鱼的外形对比，身体／花纹创作参考 |
| 一种明确身份的海葵 | 生物关系、形态与动态 | 图鉴关系样本及环境观察；具体物种在 A 批核对 |
| 珊瑚礁环境主题包 | 沙地、岩石、珊瑚区域、光与空间 | 海洋环境构图和生物组合参考；选用珊瑚需记录类型，科普涉及具体物种时再核对身份 |

三种鱼沿用已有对象，新增关系和动画细节仍须查证。首批不新增鱼模型数量，不承诺深海或整套生态模拟；是否制作新环境资产由样图确定。

### C 批：样本可用后再扩展

1. 按创作主题和辨识差异补足现有 12 鱼，已有合适内容优先复用。
2. 按两钓场的环境身份补其他可观察生物；每批围绕一个场景主题，避免收集一堆无关联物种。
3. 新加坡本地内容独立列地域证据，先核对记录再选物种；不能把当前两处虚构钓场全部称作当地生态。
4. 更多创作对象、自由轮廓、完整 3D 与电视展示仍属于后续讨论；本计划只保留扩展所需资料字段。

## 4. 资料记录模板

| 记录 | 必填内容 |
| --- | --- |
| 物种身份 | 稳定项目 ID、接受学名、中文／英文名称及各自来源、常见别名、分类、幼体／成体与相似种说明 |
| 单条事实 | 事实 ID、原意摘要、来源页面与具体段落／图表位置、作者／机构、查阅日期、证据支持范围、地域／生命阶段、疑点、审核状态 |
| 外形与动作 | 整体识别特征、嘴／鳍／尾／花纹局部、不同视角、游动和觅食参考；每项关联事实或参考 ID |
| 数值 | 常见值／最大值、单位、测量口径、生活条件与来源；不把最大长度当成每条鱼的日常大小 |
| 生物关系 | 两端明确对象、关系类型、地域／阶段与成立条件、证据；泛指关系与明确物种关系分开 |
| 创作联系 | 对应创作工具、孩子能观察什么、可尝试的创作想法、哪些效果属于游戏设定 |
| 儿童与亲子内容 | 一句名称介绍、点听知识、可观察问题、亲子解释；每段关联事实 ID，读音与专名待校对 |
| 展示用途 | 工坊／试游／图鉴／海洋／钓场；是否适合观察、作为灵感或出现于当前环境主题 |

事实状态建议为：待查 → 已找到证据 → 已核对 → 可发布；另记有争议／证据不足。写完儿童文案、找到图片或生成模型都不自动改变事实状态。保护状态、名称与许可等可能变化的字段，在正式内容发布前复查。

## 5. 来源入口与核对方式

本次查阅的入口用于安排检索，不表示已完成整个批次：

| 来源 | 建议用途 | 使用边界 |
| --- | --- | --- |
| [WoRMS](https://www.marinespecies.org/) | 核对接受学名、同物异名与身份 | 行为与外形需另找具体证据；记录查询日期和条目 ID |
| [Florida Museum：眼斑双锯鱼资料](https://www.floridamuseum.ufl.edu/discover-fish/species-profiles/clown-anemonefish/) | 首个样本的外形、行为与关系核对入口 | 条目含具体图片版权信息；资料可阅读不代表图片可直接入产品 |
| [Waikīkī Aquarium：黄镊口鱼资料](https://www.waikikiaquarium.org/experience/animal-guide/fishes/butterflyfishes/forceps-butterflyfish/) | 嘴形、相似种与觅食主题 | 对照明确学名，避免把相近物种的解释混用 |
| [NParks：海岸与海洋生态](https://www.nparks.gov.sg/nature/ecosystems/coastal-marine) | 新加坡地域与环境主题入口 | 优先找物种级出现记录，主题概述不等同于某物种在某地点出现的证明 |
| [Smithsonian Open Access FAQ](https://www.si.edu/openaccess/faq) | 搜索明确标注 CC0 的候选视觉素材与许可说明 | 单件核对身份、许可和限制；不认为该机构全部图片都开放，也不保证有适合游戏的素材 |

现有 FishBase、澳大利亚博物馆和中文名称来源继续作为逐条盘点起点；必要时查原始研究。重要原因解释与生态关系尽量找独立证据交叉核对。找不到支持时保留空缺；资料冲突记录各自说法和适用条件，暂不写成确定的孩子知识。

事实、游戏参数和拟人化故事分开。孩子文案用短句保留科学含义，不从大眼、颜色、尾巴大小直接推导能力，不把动画效果作为事实证据。

## 6. 素材计划：先列需求，再筛选或制作

| 素材包 | 首批建议需求 | 取得方式与准备标准 |
| --- | --- | --- |
| 真实参考图片 | 每条样本鱼优先一张可辨整体图，按知识需要补嘴／鳍／尾／花纹局部 | 先存链接和元数据；产品内展示只使用权利与用途明确的素材，无法取得合适图片时使用准确的原创示意图 |
| 动作参考 | 每个需要制作的动作一段可观察参考或对应研究说明 | 用于分析动作，不默认把参考视频嵌入游戏；没有证据时不宣称真实动作 |
| 创作部件参考表 | 身体、头、嘴、鳍、尾、花纹六类，先覆盖首批主题 | 真实局部与现有原创工具并列，说明识别特征、可编辑范围与游戏表现 |
| 场景参考与样图 | 一个海洋全景、一个作品近看、一个新鱼入海分镜 | 先定构图和原创鱼的视觉协调，再列沙地、岩石、珊瑚等所需环境资产 |
| 游戏可用图形／模型 | 现有鱼优先复用；新增局部示意、环境景物与少文字图标按样图确定 | 保存可编辑源文件；一致的朝向、尺寸、锚点、色彩与导出规范；Canvas 与 3D 用途分别记录 |
| 语音与声音 | 先写首批介绍、点听知识、必要操作与庆祝脚本；环境声音列候选需求 | 中文短语音优先作为草案，英文按需要再定；核对发音与许可后制作，保留文本及停止／重听设计 |

素材先区分“研究参考”和“产品可用”。登记资产 ID、对应对象／主题、来源 URL、作者、许可版本与证据页面、允许用途与改作条件、署名文本、修改说明、用途、尺寸／格式、质量状态及文件位置。许可不明确时只保留参考链接，标明待确认；不进入运行资源。

原创或 AI 辅助制作的图形也记录来源与制作过程，按资料检查外形和动作；生成图不作为科学证据。共享设计对话及现场照片只作为体验参考，不默认复制其展馆界面、素材或标识。

先出资料与脚本，再决定录音／合成方式、素材生产方式和预算，不先采购大包模型或录制整套百科。使用计划内开放素材仍需核对单件页面；Smithsonian 的说明仅适用于指定为 CC0 的资产及其相应条件。
