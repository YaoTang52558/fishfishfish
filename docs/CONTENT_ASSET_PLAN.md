## 下一批怎么选

先记录孩子想认识／想造什么，以及现有素材无法表达的结构。每个新增对象说明用途：观察外形、同类比较、生态问题、创作结构或钓鱼体验；只有数量增长的候选暂缓。

每批选材→核对学名／俗名／生命阶段与海域→登记来源与条件→儿童短句和亲子资料→插画／局部点位→语音→按使用场景制作模型和动作→接入→核对实际表现。不能根据图片外形推导未经核对的能力，也不把游戏运动解释成真实规律。

优先评审已有六石斑比较和特殊身形是否有用，再决定新增。海马、鳐、带鱼等需要专用创作结构时，将结构实现与观察资料分别排期。

事实修改使用 `docs/content/claims.json`、`sources.json`、`species/` 及对应脚本，保留事实 ID 与证据条件。生产检查见 `scripts/check-content-pack.mjs`；生成工具依其输入文件运行，停用的历史一次性脚本不重放。
