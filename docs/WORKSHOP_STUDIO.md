# 创作工坊品质样板：计划 1–3

2026-10-07 · 已实现首版样板 · 面向新加坡小学一年级孩子，目标设备 iPad 9 或同等平板。

打开 [创造工坊](http://127.0.0.1:5175/create)。本轮覆盖 [最新完整计划](MASTER_PLAN.md) 的整体视觉基线、工坊布局，以及创作—试游—入海—再次编辑的连贯性；审美反馈与真实平板体验仍待评审。

## 1. 画面与识别

- 工坊、借用预览、试游和作品近看共用明亮浅海水色、静态柔光与简单沙地；暗背景继续供发光笔观察。
- 暖白工具面、青绿主操作、浅色卡片和圆角保持一致。自己的海洋与工坊共用更宽的页面、紧凑导航及操作控件；图鉴缩略图也使用浅色底。
- 孩子的部件、颜色、自由笔迹、印章及存档格式不随视觉风格调整而改变。绘画时鱼和镜头保持稳定，不让动画干扰落笔。
- 当前是创作链路的视觉基线样板。两个钓场的地形差异、抛竿／拉鱼特效及上鱼画面，继续按总计划 9–11 推进；完整三维创作与海洋仍属待讨论路线。

水色基线为 `#A3DDE0 → #56ADBB → #367F91`，主操作保留 `#175F57`。海洋环境插画与原创鱼的协调性，最终由家长和孩子实际评价。

## 2. 工坊布局与部件选择

中央鱼体预览占主要宽度。平板／宽屏把尾巴、身体与鳍放在左侧，头型、眼睛和嘴放在右侧；按钮显示当前鱼的局部图像，位置对应朝右的预览。较窄手机宽度将六个图形按钮收在预览下方，保留完整绘画面积。

点一个部位，下方只显示该部位的候选；不必在多个部件长列表中寻找。身体和头型属于造型，尾、鳍、眼、嘴属于部件，原分类入口继续保留。尾巴、眼和嘴的候选按实际几何局部取景，更容易看出差异；缩略图随转屏重新绘制。

颜色／画笔在下方工具盘。比例调整收进「调一调长短、胖瘦和头的大小」，其余画笔、发光、橡皮、底色、印章和花纹能力继续可用。多选项在工具盘内滚动，近看与试游保持在画面旁。图形按钮、候选及步骤入口至少 44px；尚未把每个操作都配成语音，完整图形教学仍是计划第 5 项。

## 3. 从修改到作品入海

顶部明确显示创作、试游、入海三个入口，可以往返；试游可跳过，知识也不作为保存前提。

1. 创作时改一个部件记一步撤销。切换工具或阶段先结束当前绘画／比例手势，避免把未结束的操作带入下一阶段。
2. 试游只读展示同一份作品，短提示引导看尾巴和鳍；想修改可直接回工坊，或点「换个尾巴试试」展开尾巴。返回保留笔迹、印章与撤销历史。
3. 入海前放大、居中展示自己的鱼，继续轻轻摆尾。名字预先填好，可以直接入海，也可以修改；性格、喜欢的地方和特效收在可选项中。
4. 已有作品清楚区分「更新这条鱼」和「另存为新鱼」：更新沿用原 ID，另存保留原作并增加一条。保存进行中锁住阶段切换与表单操作，沿用提交凭证去重与失败重试。
5. 保存成功后进入既有海洋欢迎、图片卡、找鱼与再次编辑流程；不把临时试游或入海展示写成额外资产。

## 5. 本轮评审重点

先看中央鱼够不够大、能否凭图找到要换的部位、选部件时是否还能看见改动，以及试游后是否容易回改。再看默认名字是否减轻操作、更新／另存是否容易理解。收到具体反馈后调整这一段，再继续总计划其他工作。
