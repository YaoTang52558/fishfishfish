## 三种运行方式

| 方式 | 默认钓鱼 | 3D 入口 | 数据来源 |
| --- | --- | --- | --- |
| `npm run dev`，5173 | 旧版 | `/dev/fishing-3d` | 当前开发站点 |
| `npm run build` + `npm run preview`，4173 | 旧版 | 不包含 3D 开发页／运行时代码 | 正常预览站点 |
| `npm run build:3d-preview` + `npm run preview:3d`，4174 | 3D | `/fishing/:habitatId`、`/preview/fishing-3d` | 独立候选站点 |

各来源的 IndexedDB／localStorage 独立；换端口或从电脑改为平板不会自动同步作品。需要已有数据时用设置页导入备份。平板按 [G5_PLAYTEST.md](G5_PLAYTEST.md) 连接同一 Wi-Fi，IP 以本次 `ipconfig` 为准。
