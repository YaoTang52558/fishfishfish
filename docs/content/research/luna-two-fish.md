## 黄镊口鱼 `Forcipiger flavissimus`

**身份与名称**：项目 ID `forcipiger-flavissimus`；项目标签“黄镊口鱼”（未重新核对中文规范名）。Waikīkī Aquarium 页面直接将 forceps butterflyfish 对应为该学名。WoRMS 搜索列表列作 `Forcipiger flavissimus Jordan & McGregor, 1898`，接受身份核对入口：[WoRMS](https://www.marinespecies.org/aphia.php?p=taxlist&tName=Forcipiger)。注意它与 `F. longirostris` 是不同种；Aquarium 指出后者吻／颌约长三分之一。

**原子事实**（同一网页，段落按正文行号定位）：

| ID | 事实 | 来源位置与证据条件／疑点 |
|---|---|---|
| FF1 | 黄镊口鱼的学名为 `Forcipiger flavissimus`；其细长颌形似镊子。 | [Waikīkī Aquarium](https://www.waikikiaquarium.org/experience/animal-guide/fishes/butterflyfishes/forceps-butterflyfish/) 段1（页面正文 L83）；物种直接陈述。 |
| FF2 | `F. longirostris` 的颌比黄镊口鱼约长三分之一，两者共享同一夏威夷语名。 | 同上段3（L85）；仅作夏威夷两近缘种比较，勿当成本种变异范围。 |
| FF3 | 两种长吻蝴蝶鱼会探查珊瑚枝和礁石缝隙中的小型无脊椎动物。 | 同上段4（L86）；来源概括两种，不说明每次行为或每个地点都相同。 |
| FF4 | 黄镊口鱼可张口撕下较大猎物的部分，例如蠕虫触手、海胆管足；也会夹取小型甲壳类和鱼卵。 | 同上段5（L87）；物种直接陈述。措辞是“可”，不应简化成只吃某一种食物。 |
| FF5 | 该鱼分布于夏威夷群岛、印度-太平洋及东太平洋，在较浅水域更常见。 | 同上段6（L88）；Aquarium 的概括性分布／深度描述，没有在该句给出深度数值。 |
| FF6 | 页面将本种黄色与种名 `flavissimus` 及夏威夷语名中对黄叶／鱼动作的描述联系起来。 | 同上段2（L84）；这是名称词源说明，不是颜色的适应性解释。 |

**一句儿童介绍**：黄镊口鱼有一张细长的嘴，能探进礁石缝，也会夹取或撕下不同的小食物。

**点听草案**：

- 它会把长嘴伸到珊瑚枝和礁缝里找食物。（FF3）
- 它能夹取小甲壳类和鱼卵，也能撕下蠕虫触手或海胆管足。（FF4）
- 看看它的长嘴：名字里的“镊”就来自这种像夹子的嘴形。（FF1）

**创作联系**：嘴部工具可让孩子试画“细长、尖端收窄”的原创嘴形；可对照真实鱼嘴与礁缝取食。来源支持它会探缝，但不支持把所有细长嘴都设定成吸管，也不支持由外观推出特定游戏能力。身体、花纹参考可用亮黄主体和深浅分区作绘画灵感；本轮指定页面文字没列全身花纹细节，需另找带图并确认视觉细节后再定。

**图片候选**：Waikīkī Aquarium 本种页面为候选所在页面（上列链接）。本轮文字抓取没有给出页面图像作者或许可条款；作者／授权均记为未知，不能直接用于游戏。后续需打开页面核对图片署名并另行取得许可或改用明确开放授权素材。

## 纹腹叉鼻鲀 `Arothron hispidus`

**身份与名称**：项目 ID `arothron-hispidus`；项目标签“纹腹叉鼻鲀”（未重新核对中文规范名；项目 popular label 为“白点河鲀”）。澳大利亚博物馆页面标题为 Stars-and-stripes Puffer / Toadfish，学名 `Arothron hispidus`；WoRMS 将此学名列为接受名，并将 `Tetraodon hispidus`、`A. hispidus perspicillaris` 等列为异名／接受到本种：[WoRMS](https://www.marinespecies.org/aphia.php?p=taxlist&tName=Arothron+hispidus)。

**原子事实**（澳大利亚博物馆页面，段落按页面小标题与正文位置定位）：

| ID | 事实 | 来源位置与证据条件／疑点 |
|---|---|---|
| AH1 | 本种可长至约 51 厘米。 | [Australian Museum](https://australian.museum/learn/animals/fishes/stars-and-stripes-toadfish-arothron-hispidus-linnaeus-1758/) Fast Facts「Size Range」（正文 L58–61）；最大报告范围，不代表常见个体。 |
| AH2 | 背侧呈绿褐至黄褐色、腹侧白色；上侧和尾鳍有白色小点，下侧有白色至淡蓝色线纹。 | 同上「Identification」（L68–70）；该页描述的识别外观，不推出花纹功能。 |
| AH3 | 胸鳍基部与鳃口周围有深浅相间的环纹。 | 同上「Identification」（L70）；可作为局部观察点。 |
| AH4 | 身体圆；背鳍靠后，位置与大小相近的臀鳍相对。 | 同上「Identification」（L71）；页面说这是许多河鲀科鱼类的典型体形，勿视为本种独有。 |
| AH5 | 栖息环境从河口到珊瑚礁；分布于印度-太平洋热带及暖温带海域。 | 同上「Habitat」「Distribution」（L72–79）；广域概括，不能据此证明当前游戏钓场代表真实产地。 |
| AH6 | 食物包括藻类、珊瑚、海绵、海星、软体动物、海葵及其他无脊椎动物；上下颌牙齿融合成两块板状结构，嘴呈喙状。 | 同上「Feeding and diet」（L87–89）；食物清单不表示每个个体或每地都取食全部项目。 |

**一句儿童介绍**：纹腹叉鼻鲀身体圆圆的，背上有白点，腹侧还有浅色线纹。

**点听草案**：

- 它背上有白色小点，身体下侧有浅色线纹。（AH2）
- 看看胸鳍前面和鳃口周围，能找到一圈圈深浅相间的纹路。（AH3）
- 它的嘴像小喙，能吃藻类、海绵和多种小动物。（AH6）

**创作联系**：身体工具可借鉴圆润、较饱满的轮廓；花纹工具可试“背部白点＋腹侧浅线＋胸鳍根部环纹”分区组合。真实页面支持这些可见特征，不支持把圆身说成游得慢或更安全。当前游戏外形可作创作草图，不等于经过准确性审查。

**膨胀与“气囊”核查**：现有代码草案“体内有气囊，能让肚子迅速鼓起来”没有在本轮物种专页找到依据。检索到一篇关于夏威夷病弱／死亡河鲀的论文提及 `A. hispidus` 病鱼有胃膨胀及胃内不同量的水；这是异常个体观察，不能证明健康本种正常防御膨胀的机制，更不能称独立“气囊”。因此本物种的正常膨胀机制与器官表述均**待查**；儿童文案暂不讲膨胀。参考：[论文](https://www.int-res.com/articles/dao_oa/d123p087.pdf)，研究对象包括多种河鲀，所见病理不可泛化。
