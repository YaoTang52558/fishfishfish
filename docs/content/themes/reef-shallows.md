# 自己的海洋：珊瑚浅海主题包

2026-10-06 · 环境主题与原创成品；珊瑚全景、作品近看、入海三幅分镜已制作，没有新增环境 GLB。

## 体验目标

孩子能找到自己造的鱼、近看花纹、让鱼游过来，再回去编辑。环境要有光、水和空间层次，并留出清楚观看作品的水域。场景美术可明亮，但每处景物应有构图作用。

这是泛珊瑚浅海主题，三鱼各有礁区相关资料，不代表已查明它们与海葵在某个新加坡地点同时出现。虚构家园里的幻想鱼清楚作为孩子作品；真实生物卡需要对应物种。地域记录见 RM-02，不据此包装成某真实海岸复原。

## 生物知识底稿

RF-01–RF-03 记录在 [事实表](../claims.json)，来源为 [Smithsonian Ocean](https://ocean.si.edu/ocean-life/invertebrates/corals-and-coral-reefs)：珊瑚的动物身份、石珊瑚骨骼、许多温暖浅水珊瑚与藻的关系。这些是概括资料，不是具体珊瑚物种模型的鉴定依据。

一开始可观察“小丑鱼与海葵”（REL-AO-RM）。暂不新增触摸、喂养、捕食连锁或完整生态模拟。海葵、珊瑚是观察对象；环境动物是否能钓要按对象另定。

## 三张原创分镜的制作要求

| 样板 | 画面安排 | 评价问题 |
| --- | --- | --- |
| 海洋全景 | 前景少量岩石与沙坡，中景留宽水域给作品，后景礁体与蓝色深度；作品较亮且可找到 | 一眼能找到自己的鱼吗？鱼与环境会不会混在一起？ |
| 作品近看 | 鱼靠近后放大，保留原始笔迹与花纹；背景简化，画面内有返回绘画入口 | 能看清自己的笔触吗？主要操作是否顺手？ |
| 新鱼入海 | 新作品由入口游入、短暂靠近、加入海洋；有可停止／略过的短提示 | 是否感觉它进入了自己的世界？会不会拖长等待？ |

## 首批资产与动态需求

| 项目 | 用途 | 制作前要知道什么 |
| --- | --- | --- |
| 沙地与礁石 | 区分底部／边界，建立层次 | 几何、明暗、重复纹理与镜头距离；纯环境示意无需假称某真实地点 |
| 石珊瑚形态组 | 表现礁区和形态差异 | 先列拟用形态与类型；若科普命名具体物种，补身份和外形证据 |
| 海葵 | 关系观察点 | 形态与附着补 RM-03／RM-04 原始研究；插画已制作，真实动态仍需另核 |
| 水光、粒子、背景流动 | 气氛与空间感 | 属美术效果；不把粒子自动说成浮游生物，不宣称光照复原某地 |
| 原创鱼与短动作 | 画面主体，呼唤、靠近、追泡泡 | 保存作品花纹；动作是交互表现，真实行为解释另核证据 |
