# 夏鲆（比目鱼）

Paralichthys dentatus · 鱼 · 2026-10-07

![原创活体观察示意](../../../public/content/v1/illustrations/paralichthys-dentatus.webp)

两只眼在同一侧，幼鱼发育前不同。

- **扁扁的身体**：夏鲆身体扁平，上面较深，下面较白。（VTH-AQ-01）
- **眼睛搬家**：它长大时，右边的眼睛会移到身体左边。（VTH-AQ-02）
- **颜色会变化**：它能改变身体颜色，配合周围海底的样子。（VTH-AQ-03）
