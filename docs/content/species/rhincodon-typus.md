# 鲸鲨

Rhincodon typus · 鱼 · 2026-10-07

![原创活体观察示意](../../../public/content/v1/illustrations/rhincodon-typus.webp)

鲸鲨是鱼，不是鲸。

- **点点和格纹**：鲸鲨的深色背部有浅色点点和条纹。（VTH-AS-01）
- **宽头大嘴**：它的头很宽、很平，嘴在头部前方。（VTH-AS-02）
- **过滤食物**：它能把水吸进大嘴，过滤浮游动物和其他小食物。（VTH-AS-03）
