## 亲子展开草案

小丑鱼：典型三白带可从头到尾观察，颜色还有地域差异。宿主关系只对明确物种讲；黏液与适应过程见 AO-04，不能告诉孩子所有鱼都能安全进海葵。更深的机制另查研究。

黄镊口鱼：可以在绘画时对比嘴形；FF-03、FF-04 支持探缝、夹取和撕取不同食物，不把长嘴当吸管或统一游戏能力。

纹腹叉鼻鲀：点、线、环可分区观察，再自由组合到作品。AH-06“气囊”机制待查，首批不讲；真实泳姿未核对，不以圆身推断速度。

这些是游戏状态提示，不是生物事实。实际接入时复用已有适合的提示，避免两套声音竞争。

## 试录与校对单

- 先试 VO-AO-INTRO／BANDS／FINS／HOME，再判断音色、节奏和词汇；别一次录全套百科。
- “鳍、鳃、喙、鲀”和学名不会强制出现在幼童入口；图形定位应先清楚。规范中文名的独立念法待校对。
- “这里”“这种”必须有准确高亮／当前对象，否则改成能独立理解的完整句。
- 录音或合成后登记声音来源、使用许可、文本版本与文件位置；停止与重听设计随样板验证。
